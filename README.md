# Tiny Stack VM

A faithful interpreter of make.fun's tiny stack ISA v1, for the
`tiny-stack-vm-01-run-20261122` bounty. `main.ts` (Node 22, no dependencies)
answers a whole set in one run: `/input/<id>/program.bin` + `input.bin` ->
`/output/<id>/stdout.bin` + `exit.txt`. MIT — see `LICENSE`.
